# Calisthenics Guide

A simple and clean frontend project that helps users explore calisthenics exercises by category, difficulty, and muscle group.  
Built with **Next.js**, **TypeScript**, and **TailwindCSS**.

### 🚀 Live Demo
https://calisthenics-guide-flame.vercel.app

---

## 📁 Tech Stack
- Next.js 16
- TypeScript
- TailwindCSS
- Frontend-only

---

## 📦 Features
- Browse calisthenics exercises with images and descriptions
- Filter by difficulty & muscle group
- Responsive UI
- Fast and clean Next.js architecture

---

## 🛠️ Getting Started

```bash
npm install
npm run dev
npm run build
```
